# 琉璃打砖块

夜空极光下的打砖块游戏。左右移动球拍，把星光球弹回去，敲碎所有琉璃砖。

直接用浏览器打开 `index.html` 就能玩，不需要安装任何东西。

## 砖块

| 砖块 | 特点 |
| --- | --- |
| 彩色砖 | 一下就碎，偶尔掉道具 |
| 翡翠砖 | 要打两下才碎 |
| 紫晶砖 | 要打三下才碎 |
| 金砖 | 一定掉一个好道具 |
| 赤焰砖 | 会爆炸，炸碎周围一圈 |
| 钢砖 | 打不碎，只有火球能熔掉 |
| 暗影砖 | 掉神秘道具，多半是坏的 |

## 砖块风格

| 风格 | 样子 |
| --- | --- |
| 星夜 | 夜空极光下的琉璃砖 |
| 春樱 | 砖顶长满青苔，开着樱花和小雏菊，樱花瓣飘落 |
| 秋叶 | 砖上落着枫叶、银杏叶，黄昏里落叶纷飞 |
| 冬雪 | 砖顶盖着厚厚的积雪，底下挂着冰凌，大雪飘落 |
| 糖果 | 砖顶淋着草莓、巧克力、薄荷、香草糖霜和彩针糖 |

标题页可以选「随关卡」（五种风格一关一换）或固定一种。积雪、青苔、落叶、糖霜都是真正的 3D 模型，会被小球照亮、在砖上投下影子；砖块碎掉时雪会散成雪粉，叶子和花瓣飘落，彩针糖四处蹦开。

## 背景音乐

每种风格有自己的原创曲子，用 Web Audio 实时合成，没有音频文件：

- 星夜：钢片琴和柔和铺底，慢而梦幻
- 春樱：拨弦，轻快明亮
- 秋叶：长笛和吉他，温暖的小调
- 冬雪：八音盒加雪橇铃
- 糖果：跳跳的方波旋律配拍手

换风格时音乐在下一小节切换；暂停和过关时音乐变小，游戏结束时停止。右上角有单独的音乐开关（键盘 B），音效开关是 M。

## 续关

球用完时有三种选择：

- **接着打**：补满 3 个球，已经打碎的砖块保留，分数接着累计，次数不限，可以一直打到过关。
- **从第 N 关重来**：这一关的砖块全部重置，分数从 0 算起。
- **从第 1 关开始**。

标题页也会记住上次打到第几关，显示「继续第 N 关」。

## 道具

好的：加长、分裂、激光、火球、慢速、磁力、护盾、生命
坏的：缩短、加速

## 操作

- 电脑：鼠标或 ← → 移动，空格或点击发球，P 暂停，B 音乐，M 音效
- iPad / 手机：手指放在屏幕任意地方左右拖动，球拍跟着拖动的距离走（不用按在球拍上，手指不会挡住球拍），轻点发球；拖动瞄准后松手不会发球
- 发球时 5 秒不操作会自动发球

## 落点提示和简单模式

标题页和暂停菜单里有两个开关，会记在浏览器里：

- **落点提示**（默认开）：球往下落时，在球拍下方画一个发光的圈，球拍上方有个小箭头，标出球会落在哪里（左右墙的反弹也算进去）。圈是绿色说明球拍已经接得住，黄色说明要挪过去。好几个球时最多标 4 个，最先落下的那个最亮。球路上还会撞到砖块时不显示。
- **简单模式**（默认关）：球慢一些，球拍宽 30%，球拍两端接球更宽容，每发一个球都自带一层护盾。

## 技术说明

- 单个 HTML 文件，音效全部用 Web Audio 实时合成，没有音频文件。
- 砖块用 three.js（0.170.0，从 jsDelivr 加载）以 WebGL 实时渲染成 3D 模型；
  浏览器不支持 WebGL 或加载失败时，自动改用 2D 平面琉璃砖。
- 最高分和静音设置保存在浏览器本地。
